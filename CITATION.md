# How to cite

Please cite this repository when using it in publications or derivative projects.

Recommended citation (APA):

Bharti, S. (2026). *GeneScout: an agentic evidence-review workbench for gene prioritization* (version 0.1.6) [Software]. Zenodo. <https://doi.org/10.5281/zenodo.21352389>

BibTeX:

```bibtex
@software{genescout_2026,
  author  = {Bharti, Samuel},
  title   = {GeneScout: an agentic evidence-review workbench for gene prioritization},
  version = {0.1.6},
  date    = {2026-10-08},
  doi     = {10.5281/zenodo.21352389},
  url     = {https://doi.org/10.5281/zenodo.21352389}
}
```

Notes:

- `10.5281/zenodo.21352389` is the concept DOI, and it always resolves to the
  latest version. To cite one specific version, use that version's DOI from the
  Zenodo record. `CITATION.cff` lists the DOI of each version.
